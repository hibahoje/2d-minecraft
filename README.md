# 2D Minecraft Game

This is a simple 2D Minecraft-style game made with HTML, CSS, and JavaScript.

## How to Play

1. Open the game and choose a tool from the toolbar.
2. Click on a matching block in the world.
3. The block will be removed and added to your inventory.
4. Click an item in the inventory to select it.
5. Click on an empty space in the world to place the block.
6. Use the reset button to return the world to its original state.

## Tools

* **Axe** - removes tree and wood blocks.
* **Pickaxe** - removes rock blocks.
* **Shovel** - removes dirt blocks.

## Game Features

* Pre-generated 2D Minecraft-style world.
* Different types of blocks.
* Tool selection.
* Inventory system.
* Ability to remove and place blocks.
* Reset world button.
* Separate landing page and tutorial.

## Technologies

* HTML
* CSS
* JavaScript
