# 2D Minecraft 

## Description

I built a simple 2D Minecraft-style game using HTML, CSS, and JavaScript.

The game has a pre-generated world with grass, dirt, rock, tree, and wood blocks. The player can use different tools to remove blocks and collect them in the inventory. Blocks from the inventory can also be placed back into empty spaces.

The project also includes a landing page with a tutorial that explains how to play.

## What I found hard

The hardest part for me was making the JavaScript work with the world and inventory.

I had to understand how to use a 2D array for the world, how to remove blocks when clicking on them, and how to add the removed blocks to the inventory.

It was also challenging to make the tools work only with the correct types of blocks and to make the reset button return the world to its original state.

## Known bugs

Currently, there are no known major bugs.

## Assignment review

I liked the assignment because it allowed me to make something interactive instead of only writing separate HTML, CSS, and JavaScript exercises.

The JavaScript part was the most challenging for me, especially working with the world array and inventory. However, it helped me understand how JavaScript can be used to control what happens on a webpage.

Overall, the assignment was challenging but helped me practice HTML, CSS, JavaScript, and Git.
